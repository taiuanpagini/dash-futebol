## Task Execution

When implementing tasks from `tasks.md`:

- Work through tasks in phase order (Phase 1 → Phase 2 → Phase 3+).
- Respect dependencies — do not start a task before its prerequisites are complete.
- Tasks marked `[P]` can run in parallel if they touch different files.

- Commit after each task or logical group of parallel tasks.
